Pixel MD 개인정보 처리방침

시행일: 2026년 11월 26일 · Pixel MD iOS 버전 적용

한 문장으로: Pixel MD는 어떤 데이터도 수집하지 않습니다. 앱은 완전히 오프라인으로 동작합니다——계정 없음, 서버 없음, 통계 없음, 광고 없음, 타사 SDK 없음, 네트워크 요청 없음. 노트는 항상 사용자가 선택한 폴더에만 존재합니다.

1. 앱이 접근하는 데이터

  • 노트 파일: 시스템 파일 선택기에서 지정한 폴더의 파일. 편집·미리보기·내보내기를 위해 기기에서만 읽고 쓰며, 별도 복사본을 만들지 않고 업로드하지 않습니다.
  • 앱 설정: 테마, 글꼴, 도구 모음, 정렬 방식 등의 환경설정은 기기의 앱 설정에 저장되며 앱을 삭제하면 함께 지워집니다.
  • 색인과 캐시: 목록 로딩을 빠르게 하기 위해 메모리나 기기에 임시로 생성되는 데이터로, 기기 밖으로 나가지 않습니다.

2. 네트워크

Pixel MD는 어떤 네트워크 요청도 보내지 않으며 비행기 모드에서도 모든 기능이 동작합니다. 광고, 분석, 충돌 보고, 타사 SDK가 포함되어 있지 않습니다.

다음 시스템 기능은 iOS가 제공하며 데이터가 당사를 거치지 않습니다: iCloud Drive 동기화는 시스템이 담당하고(폴더가 iCloud Drive에 있는 경우), 받아쓰기는 Apple의 기기 내 인식 모델을 사용합니다.

3. 권한 안내

  • 파일 접근: 사용자가 직접 선택한 폴더에만 접근하며 언제든 폴더를 바꿀 수 있습니다.
  • 카메라: 종이의 글자를 촬영해 기기에서 인식합니다. 사진은 업로드되지 않고 사진 보관함에 저장되지 않습니다.
  • 마이크 및 음성 인식: 음성 입력은 시스템의 기기 내 받아쓰기 모델(iOS 26 이상)을 사용하며 인식은 기기에서 이루어집니다.
  • Face ID: 앱 잠금 해제에만 사용되며 인증은 시스템이 수행합니다. 당사는 생체 인식 데이터에 접근하지 않습니다.

4. 하지 않는 일

  • 노트나 개인정보를 수집·업로드·판매·공유하지 않습니다.
  • 프로파일링이나 앱·웹사이트 간 추적을 하지 않습니다.
  • 충돌 수집, 행동 분석, 광고 SDK를 사용하지 않습니다.

5. 아동 개인정보

앱은 아동을 포함한 누구의 데이터도 수집하지 않습니다. 계정, 소셜 기능, 광고가 없습니다.

6. 데이터 삭제

노트는 전적으로 사용자가 관리합니다. '파일' 앱이나 앱 안에서 파일을 삭제하면 됩니다. 앱을 삭제하면 설정과 캐시는 지워지지만 노트 파일은 삭제되지 않습니다.

7. 방침 변경

향후 버전에서 데이터 처리 방식이 바뀌면 이 페이지를 먼저 갱신하고 시행일을 수정합니다. 무네트워크는 설계 원칙이므로 데이터 수집 구성 요소를 추가하지 않습니다.
